# Фільми

Консольний список фільмів з оцінками і статусами.

    Назва:         Фільми
    Для кого:      для мене, щоб пам'ятати, що я подивилась, як мені сподобалось і що хочу подивитись
    Запис:         назва, рік, статус, оцінка, дата
    Операції:      додати, показати всі, знайти за назвою/статусом/роком/оцінкою, звіт
    Звіти:         кількість за статусом, середня оцінка, топ-3 фільми

## Запуск

Потрібен Python 3.10 або новіший. Бібліотеки не потрібні.

    python3 cli.py add "Інтерстеллар" 2014 переглянуто 9 2026-10-03
    python3 cli.py add "Дюна: Частина друга" 2024 заплановано
    python3 cli.py list
    python3 cli.py find title дюна
    python3 cli.py find status заплановано
    python3 cli.py find year 2014
    python3 cli.py find rating 8
    python3 cli.py report

Статуси: `переглянуто`, `дивлюсь`, `заплановано`.
Оцінка від 0 до 10, де 0 означає «ще не оцінено». Дата у форматі РРРР-ММ-ДД, якщо не вказана, береться сьогоднішня.

## Тести

    python3 tests.py

## Формат даних

`data.txt`, один фільм на рядок: `назва;рік;статус;оцінка;дата`

    Інтерстеллар;2014;переглянуто;9;2026-10-03

Пошкоджені рядки програма пропускає і пише попередження. Приклад даних: `example.txt`
(щоб спробувати: `cp example.txt data.txt`).
